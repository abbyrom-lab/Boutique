# 🎀 Chérie & Co. - E-commerce Coquette

Bienvenido al repositorio de **Chérie & Co.**, una simulación de tienda virtual de ropa juvenil con una estética *coquette*, elegante y romántica.

Este proyecto es una Single Page Application (SPA) construida para ofrecer una experiencia de usuario fluida, rápida y estéticamente agradable.

## ✨ Características

* **Diseño "Coquette":** Interfaz de usuario con colores pastel (rosas, blancos), tipografías elegantes (Playfair Display) y bordes redondeados.
* **Navegación SPA:** Transiciones suaves entre las 5 secciones (Inicio, Catálogo, Nosotros, Contacto, Carrito) sin recargar la página.
* **Catálogo Dinámico:** Renderizado de productos utilizando JavaScript puro.
* **Carrito de Compras Funcional:** Permite añadir productos, modificar cantidades, calcular subtotales y simular el proceso de pago ("Checkout").
* **Totalmente Responsivo:** Adaptable a dispositivos móviles, tablets y pantallas de escritorio.
* **Notificaciones (Toasts):** Alertas visuales no intrusivas al interactuar con el carrito o los formularios.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica.
* **Tailwind CSS:** Framework de CSS utilizado a través de CDN para un estilizado rápido y moderno.
* **Vanilla JavaScript (ES6+):** Lógica del carrito, manejo del estado y navegación sin librerías externas.
* **Phosphor Icons:** Biblioteca de iconos ligeros y estéticos.
* **Google Fonts:** Fuentes *Inter* (sans-serif) y *Playfair Display* (serif).

## 🚀 Cómo ejecutar el proyecto

Dado que el proyecto no requiere de un servidor backend complejo ni procesos de compilación, ejecutarlo es muy sencillo:

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/cherie-coquette-store.git
   ```

2. **Navega al directorio:**
   ```bash
   cd cherie-coquette-store
   ```

3. **Abre el archivo principal:**
   Simplemente haz doble clic en el archivo `index.html` para abrirlo en tu navegador web predeterminado, o utiliza una extensión como *Live Server* en VS Code para una mejor experiencia de desarrollo.

## 📦 Estructura del Proyecto

Para mantener la simplicidad y portabilidad, todo el proyecto está contenido en un único archivo:

* `index.html`: Contiene el maquetado HTML, los estilos configurados de Tailwind CSS en la etiqueta `<style>`, y toda la lógica de estado e interactividad en la etiqueta `<script>` final.

## 🌐 Despliegue (Deploy)

Este proyecto está listo para ser desplegado de forma gratuita en **GitHub Pages**:

1. Ve a la pestaña **Settings** (Configuración) de tu repositorio en GitHub.
2. Navega a la sección **Pages** (Páginas) en el menú lateral izquierdo.
3. En la sección **Build and deployment**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
4. Haz clic en **Save** (Guardar). ¡En un par de minutos tu sitio estará en vivo!
